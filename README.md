# Float Market Watch

一个自用的 A 股、场内基金和黄金悬浮盯盘桌面应用。点击置顶小窗，在「自选行情」和「黄金」之间切换。收起后，小窗会轮播所选市场，重启时记住上次选择。

## 功能

- A 股和场内基金行情展示
- 黄金面板先显示已选账户（默认招行），再依次显示伦敦金、纽约黄金和上金所 Au99.99。点击「选择账户」可按银行和购买渠道多选，每 15 秒刷新行情。点击铃铛可设置到价提醒。
- 在账户卡片点「设置持仓」，填写成本均价（元/克）和购买克重。每克盈亏按客户卖出价减去成本均价计算，乘以克重即为预估总盈亏，未计手续费。各账户独立保存持仓和提醒，取消勾选后仍可恢复。
- 半透明置顶悬浮小窗
- 点击展开行情面板
- 自选列表本地保存
- 价格上穿/下穿提醒
- 系统托盘显示、隐藏、刷新和退出
- Windows 安装包和便携版打包

## 数据来源

银行直销报价来自招商银行、建设银行和工商银行。京东金融渠道可选民生、浙商、工商、广发、兴业、中信和浦发积存金。请按实际购买渠道选择账户。银行账户使用人民币元/克，报价缺失时显示「暂无报价」并暂停估值和提醒。

三项市场行情来自新浪。伦敦金 XAU 和纽约黄金 GC 按美元/金衡盎司显示，上金所 Au99.99 按元/克显示。

支持的代码示例：

- `600519` / `600519.SH`
- `300750` / `300750.SZ`
- `510300` / `510300.SH`
- `159915` / `159915.SZ`
