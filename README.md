# Float Market Watch

一个自用的 A 股悬浮盯盘桌面应用。它常驻桌面置顶显示自选行情，支持点击展开面板、系统托盘、价格提醒和场内基金。

## 功能

- A 股和场内基金行情展示
- 半透明置顶悬浮小窗
- 点击展开行情面板
- 自选列表本地保存
- 价格上穿/下穿提醒
- 系统托盘显示、隐藏、刷新和退出
- Windows 安装包和便携版打包

## 数据来源

当前版本使用新浪行情接口作为自用行情源。该接口适合个人学习和自用盯盘，不建议用于商用、公开行情分发或对实时性有严格要求的场景。

支持的代码示例：

- `600519` / `600519.SH`
- `300750` / `300750.SZ`
- `510300` / `510300.SH`
- `159915` / `159915.SZ`

## 开发

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
pnpm dist:win
```

如果需要重新生成 Windows 图标：

```bash
pnpm icons
```
