# Float Market Watch

一个自用的 A 股、场内基金和黄金悬浮盯盘桌面应用。点击置顶小窗，在「自选行情」和「黄金」之间切换。收起后，小窗会轮播所选市场，重启时记住上次选择。

## 功能

- A 股和场内基金行情展示
- 黄金面板每 15 秒查询招行积存金、上金所 Au99.99、伦敦现货金和纽约黄金。点击品种右侧的铃铛可设置上下限提醒。
- 在招行积存金卡片点击「设置成本均价」，按元/克填写并保存。面板和小窗按招行客户卖出价显示每克浮盈或浮亏，重启后保留成本设置。
- 半透明置顶悬浮小窗
- 点击展开行情面板
- 自选列表本地保存
- 价格上穿/下穿提醒
- 系统托盘显示、隐藏、刷新和退出
- Windows 安装包和便携版打包

## 数据来源

招行黄金账户直接读取招商银行的客户卖出价和客户买入价（元/克）。持仓赎回看客户卖出价，小窗和该品种的到价提醒也使用这个价格。实际成交以招行下单时的报价为准。

其他行情使用新浪财经。上金所 Au99.99 按元/克显示，伦敦金 XAU 和纽约黄金 GC 按美元/金衡盎司显示。每条黄金报价带有来源时间，接口缺失、暂停报价或报价过旧时会显示状态。

支持的代码示例：

- `600519` / `600519.SH`
- `300750` / `300750.SZ`
- `510300` / `510300.SH`
- `159915` / `159915.SZ`

```bash

```
